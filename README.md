# Alumni Mentorship Hub

A ServiceNow application that connects students with alumni mentors. Built using ServiceNow Studio, Flow Designer, and GlideRecord scripting to automate mentorship matching and communication workflows.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Platform | ServiceNow Studio |
| Automation | Flow Designer |
| Scripting | GlideRecord (server-side JavaScript) |
| UI | ServiceNow Service Portal |

## Key Features

- Mentor–mentee matching workflow
- Automated email notifications via Flow Designer
- GlideRecord scripts for dynamic data queries
- Demo recordings of end-to-end workflows
